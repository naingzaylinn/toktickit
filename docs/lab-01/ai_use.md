## Reflection

My prompts became better when I included the exact acceptance criteria and clearly limited the agent to the current Issue. I also told the agent not to run Git commands so that I could perform and understand the Git workflow myself.

I learned that AI-generated changes still need to be checked carefully. During Issue 1, unnecessary JavaScript files appeared beside the TypeScript files, so I removed them and verified the project again. Reviewing the implementation plan, code changes, automated tests, and manual behavior before committing helped me identify problems instead of accepting every generated change automatically.
